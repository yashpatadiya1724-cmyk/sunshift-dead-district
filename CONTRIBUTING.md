# Contributing to SUNSHIFT: Dead District 🧟

Thank you for your interest in improving *SUNSHIFT: Dead District*! Here is how you can help us keep the project clean, fast, and bug-free.

---

## 🌿 Branch Naming Guidelines
Always branch off `main` using descriptive prefix categories:
- `feat/feature-name` (e.g., `feat/minimap-zoom`)
- `fix/bug-description` (e.g., `fix/zombie-stuck-in-wall`)
- `perf/optimization` (e.g., `perf/instanced-streetlights`)
- `chore/task-name` (e.g., `chore/bump-three-version`)

---

## 💬 Commit Convention
We follow the [Conventional Commits](https://www.conventionalcommits.org/) specification:
- `feat: add objective marker indicator on HUD`
- `fix: resolve sound clipping when multiple zombies groan simultaneously`
- `perf: eliminate Vector3 allocations inside entity tick loop`
- `docs: update itch.io deployment steps in README`
