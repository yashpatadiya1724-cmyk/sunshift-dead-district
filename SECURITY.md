# Security Policy — SUNSHIFT: Dead District

## Supported Versions

| Version | Supported |
|---|---|
| `1.0.x` | ✅ Yes |

## Reporting a Vulnerability

We value security and responsible disclosure. If you identify a potential security vulnerability within SUNSHIFT: Dead District:

1. **Private Disclosure:** Please open a private security advisory on GitHub or contact the maintainers.
2. **Details:** Include steps to reproduce, impact assessment, and affected modules.
3. **Response SLA:** Maintainers review submissions and respond promptly within 48 hours.
